## Project Scope
The scope of the project involves the development of a comprehensive web and mobile application for a property listing platform. Users will be able to browse and view all listed properties, register or login to their accounts using OTP verification,access a dashboard for profile management, post property requirements, receive proposals and bid requests from agents, view property details with multimedia content, view agent personal details upon accepting a proposal, and engage in chat with connected agents.  The platform will include an inbox for messages from agents and sellers, and users will make payments and set up agreements outside the platform for property purchases. Agents, on the other hand, will create accounts, purchase subscriptions, post properti es with media content, view their property listings and user-posted requirements, send proposals or bids using connection points (deducted for each bid), recharge their accounts when depleted, and communicate with users through the chat feature. Admins will receive notifications, define connection point packages and agent account creation subscriptions, have the authority to block or disable accounts and manage web application content. The project will encompass the development of bothweb and mobile applications.

# Real Buyerz - UI/UX Design
 Real Buyerz is a Web and Mobile App product targeted for the Real Estate market that provides a central platform for property buyers and real estate agents to interact with each other. The catchy thing about this product is the ability to be able to do live bidding on the real estate requirements of users.
 
## Project Requirements
The UI/UX of the project is sub-categorized into the following types:
1. Responsive User Web Application UI/UX: This is the UI/UX available to the user and the agent to do live bidding and exchange information.
2. Responsive Admin Web Application UI/UX: This is the UI/UX design for an admin panel that will be used to monitor the activity and statistics of User Web Application.
3. Mobile Application: This mobile application is a mobile version of the User Web Application to facilitate easier bidding and communication between users and agents.

 # User Flow 
• Users can view all listed properties on our platform. 
• If the user wants to buy any property, then they need to register themselves. 
• If the user already has an account, they will login, otherwise, they will create an new account. 
• The verification will be done by OTP using an email or phone number.  
• The user will be notified after login. 
• After login, users can access their dashboard, where they can perform the below activities. 
• The user can update or delete their profile. 
• The user can post their desired property requirements.  
• The user will get notified if any agent sends them a proposal or b id request. 
• The user can view property details (description, location, images, and video). 
• When the user accepts the proposal request, the user can vie w the agent's personal details. 
• When the user accepts the agent request, the chat feature will automatically open between the user and agent.  
• Inbox displays all messages from agents and sellers. 
**Note:** users can chat with only their connected agents.  
• If users want to buy any property, they will pay the payment and set up an agreement outside the platform.

# AGENT/SLLER FLOW
• Agent will login or create their account (full name, contact information, email, location, etc.). 
• If the agent creates their new account, t hey need to buy a subscription. 
• Agents will be notified when they create an  account.  
**Note:** initially, the agent or seller will pay $1000 and 100 connection points for making their account, and to continue accessing their account, their amount will be automatically deducted from their account (a recursive process).   
• If the agent's or seller's account becomes empty, they cannot access it until they recharge their account. 
• The agent or seller can also change or add another account in case their previous account becomes empty or they don’t want to recharge their account. 
• After login, agents can get access to their dashboard, which contains the following features: 
• Agents can post their property by adding 5 (minimum) or 20 (maximum) pictures, 1 video, and a description.  
• Agents can view all their property listings. 
• Agents can view all user-posted property requirements.  
• Agents can send a proposal or bid on any user request if they find their property meets the user-defined requirements. 
• On each proposal or bid, the agent will use their connection point.  
**NOTE:** If the property price is below $80k, 10 connection points will be deducted from the agent account on each bid; these packages will be defined by the client later. 
• If agents use all their connection points before the month, they buy packages for connection points like below:  
o  300 connection to $300 
o  600 connections for $500 
• Agent proposal or bid request to the user  
• If the user accepts their proposal or bid , then the chat feature will be automatically enabled for both the user and agent. 
• All dealings and payments will be handled outs ide the platform. 
**Note:** Connection will be deducted at each proposal, not for accepting the proposal by the user. A point will be deducted initially when the agent sends a bid or proposal, even if the user does not accept that proposal.  
• The agent will be notified if any user accepts their proposal. 
• Agents can update or delete their profile.  
**Note: **if the agent deletes their account, then all property and exiting users will be automatically deleted.
